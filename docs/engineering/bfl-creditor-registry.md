# Реквизиты кредитора из официального реестра

При анализе работы БФЛ сервер ищет юридическое лицо по ИНН или ОГРН, указанным рядом с названием кредитора в справке или договоре. Если идентификаторов нет, ищет по названию организации из источника. Для банка или МФО используется Банк России. Для других юрлиц и дополнительной сверки используется ФНС.

- Банк России возвращает сведения финансовых организаций через [FinOrg](https://www.cbr.ru/FO_ZoomWS/FinOrg.asmx). Для проверки открывается карточка участника по ОГРН.
- Сервис ФНС [«Прозрачный бизнес»](https://pb.nalog.ru/) использует сведения [ЕГРЮЛ](https://egrul.nalog.ru/index.html) и отдаёт адрес и реквизиты из записи о юридическом лице. Ссылка в проверке открывает поиск по ОГРН. При недоступной карточке можно сверить неполное совпадение по данным поиска. Если ФНС требует капчу, автоматический запрос завершается со статусом недоступности.

На шаге проверки у предложений видны название, реквизиты, ссылка, дата проверки и фрагмент исходного документа. Одноимённые организации показаны отдельно. Кнопка подстановки изменяет реквизиты уже связанного обязательства и сохраняет остальные значения строки. Если обязательство ещё не подставлено, сначала выберите его по справке или договору. Сохранённые реквизиты используются в заявлении и списке кредиторов. При сбое поиска ранее сохранённые сведения и исходники доступны.

Во внешний запрос идут только реквизиты юридического лица. Ответы реестров ограничены полным и кратким наименованиями, ИНН, ОГРН, адресом и доступными КПП или БИК.
