# Работа по пакету документов

Поручение пользователя: выбирать пакет, содержащий один или несколько документов. Первый пакет — заявление о банкротстве, опись имущества и список кредиторов из предоставленных DOCX.

Это пересматривает привязку работы к одному шаблону из ADR 0005. Работа фиксирует версию пакета; пакет фиксирует упорядоченные версии шаблонов. Общие сведения и решения юриста принадлежат работе. Генерация фиксирует редакцию сведений и отдельные файлы результата. Добавление документа в каталог не меняет уже созданные работы или результаты.

Каталог поставляется с кодом и проверяется по контрольным суммам; редактирования каталога пользователем пока нет. Связи каталога, работы и файлов генерации защищены БД. Старый технический пакет доступен для чтения существующих работ, но не предлагается в каталоге UI. Создание через API исторической версии пока поддерживается для совместимости старых клиентов.

Повторяющиеся сведения представлены массивами строк с определёнными колонками. Неизвестный состав (`null`) отличается от явно указанного отсутствия (`[]`). Отсутствие сведений не становится утверждением об отсутствии имущества, долгов или судимости. Формулировки конкретного дела и его персональные данные удаляются из поставляемых шаблонов. Исходные DOCX сохраняются без изменений и не используются как runtime-зависимость.

HTML-предпросмотр строится из обезличенного бланка с полями. Он приближает оформление Word, но не обещает идентичную пагинацию. DOCX формируется из исходного OOXML-бланка с сохранением стилей, таблиц и нумерации. Юридическая актуальность формулировок требует отдельного согласования и не выводится из прохождения технических проверок.
