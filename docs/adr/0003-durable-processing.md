# PostgreSQL хранит намерение обработки, очередь доставляет работу

5 ноября 2026. Прямое последовательное сохранение дела и отправка задания в Redis оставляет окно потери работы. Выбраны запись запуска и outbox в одной транзакции PostgreSQL, повторяемая доставка в BullMQ и идемпотентное принятие результата по версии входных данных.

Гарантия — повторяемая доставка с защитой результата от дублей; exactly-once для внешних OCR/LLM-вызовов не обещается. После сбоя запрос мог выполниться у провайдера без сохранённого локального ответа. Такой расход учитывается отдельно от однократного принятия результата.

Outbox добавляет диспетчер и процедуру сверки состояния, но сохраняет задания при сбоях Redis и позволяет позже разделять worker-пулы без смены пользовательской модели прогресса. Диспетчер первоначально работает внутри worker, отдельное приложение ему не требуется. Механика и границы гарантии: [data-and-jobs.md](../engineering/data-and-jobs.md).
