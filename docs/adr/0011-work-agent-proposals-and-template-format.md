# Выводы агента, продолжение анализа и форматы подстановки

Сведения, извлечённые из цитаты, и выводы агента имеют различимое происхождение. Правило действует для любых полей. Агент может предложить недостающее сведение и объяснить, на каких данных оно основано. Вывод без независимой проверки показывается с соответствующей отметкой. Вывод, предложенный на проверку, подставляется после принятия юристом.

Дополнительный файл дополняет работу. Если источник подтверждает прежнее значение, он добавляется к этому значению. Если источник заполняет пробел, он добавляет новый факт или предложение по действующим правилам. Если значения расходятся, прежнее значение сохраняется и рядом появляется вариант для проверки. При открытом расхождении DOCX можно сформировать из текущей редакции сведений. Разные записи одного значения сводятся к одному сведению со всеми доступными исходными цитатами.

Каждое место подстановки в версии шаблона хранит строковый `placeholder` через Prisma и указывает на используемое сведение. Значение даты или суммы приводится к единому типизированному представлению. Предпросмотр и DOCX применяют один формат подстановки для данного места шаблона.

Агентская сессия продолжает использовать Mastra и ограничивает контекст по бюджету выбранной модели. Актуальные сведения и исходные фрагменты остаются доступны для сверки. База фиксирует расход каждого фактического обращения к облачной модели, в том числе повторов и ошибок. Неизвестный расход учитывается явно. Суммы по этапу, запуску и работе выводятся из этих записей.

Автоматический анализ и будущий чат продолжают одну агентскую сессию работы по [ADR 0007](0007-persistent-work-agent-session.md). Сбор истории начинается в автоматическом анализе, чтобы чат мог показать его этапы, входы, ответы и объяснения принятых решений. Записи истории сохраняют связи с исходниками и подчиняются тем же правилам доступа и удаления. Сжатие контекста меняет вход следующего обращения. История при этом сохраняет входы предыдущих обращений в пределах согласованного состава записей.

История этой сессии относится к извлечению, сопоставлению и заполнению полей работы. Отдельная расшифровка изображений выполняется в своём запуске. В сессии заполнения виден текст из файла, который фактически получил агент, и его связь с исходником.

Первичная загрузка и последующее добавление файлов используют один порядок обработки. Файлы проходят распознавание, включая чтение отдельных изображений визуальной моделью. Пока в группе есть файл в очереди или на распознавании, новые файлы работы присоединяются к этой группе. Группа закрывается, когда каждый файл успешно распознан или завершился с ошибкой. Если есть ошибка, пользователь может повторить распознавание этого файла или убрать его из работы. Группа становится готовой к анализу, когда для всех оставшихся файлов есть результат распознавания.

Готовая группа автоматически передаётся агенту заполнения. Файлы, загруженные после закрытия группы, образуют следующую группу. Они могут распознаваться в фоне, пока агент занят. Следующая готовая группа поступает в ту же сессию после завершения текущего обращения с учётом уже сохранённых сведений.

Чат показывает системные события автоматического анализа блоками со статусом, а сообщения, которые вводит пользователь, отдельными сообщениями диалога. Ответы агента показывают состояние выполнения, а детали позволяют раскрыть объяснение, вызовы инструментов и их результаты. В MVP пользователь отправляет следующее сообщение после завершения текущего обращения.

В MVP агент может читать поля и прикреплённые источники, отвечать на вопросы, предлагать сведения и править поля. По сообщению пользователя модель сама выбирает ответ или подходящий инструмент. Вызов инструмента записи сразу применяет правку через серверный сценарий правки. История показывает изменённое поле и значения до и после правки. Пользователь может выбрать прежнее значение и восстановить его для отдельного поля.

Генерация DOCX запускается из интерфейса работы. Поиск по внешним справочникам добавляется отдельно. Будущие сценарии включают поиск наименования и адреса суда по адресу регистрации и уточнение реквизитов кредиторов и банков по доверенным источникам.
