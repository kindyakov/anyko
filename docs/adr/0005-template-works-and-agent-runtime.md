# Работы по шаблону и готовый агентский runtime

Привязка к одному шаблону уточнена [ADR 0006](0006-document-packages.md): работа закрепляет пакет из 1..N шаблонов. Остальные решения runtime сохраняются.

Единицей подготовки является работа по неизменяемой версии шаблона. Отдельное дело и общие сведения нескольких работ отложены: смешивание этих сущностей увеличивает стоимость изоляции и полного удаления без принятого пользовательского сценария.

Mastra отвечает за агентский runtime, инструменты, сообщения и сессии; готовый `@ai-sdk/openai-compatible` в `@anyko/llm` подключает RouterAI и другие совместимые API. Собственный агентский цикл и отдельный HTTP-сервис моделей не вводятся. Выбор сохраняет один набор механизмов памяти, но требует включить хранилище Mastra в полное удаление исходников.

MinerU остаётся владельцем OCR/парсинга. Генеративное описание изображений выполняется через RouterAI отдельным этапом: универсальная VLM провайдера не заменяет специализированный протокол MinerU. Большие локальные LLM/VLM и GPU не требуются; небольшие модели Basic OCR остаются у MinerU.
