# Единый каталог исходных документов рабочей области

Статус: проект.

Все исходные документы рабочей области доступны через раздел «Распознавание», включая документы, загруженные при создании или редактировании работы. Храним один исходный документ и отдельную связь с каждой работой. Связь фиксирует выбранную версию готового распознавания, чтобы повторное распознавание в каталоге сохраняло прежний текст и ссылки на доказательства в существующих работах.

Каталог поддерживает серверный поиск по части исходного имени без учёта регистра и фильтрацию по нескольким форматам. Выбор работает из «Распознавания» и из работы, в том числе при её создании. Для добавления подходит последняя готовая версия распознавания, даже если более поздняя попытка ещё выполняется или завершилась ошибкой. Массовое добавление проверяет весь выбор до изменения связей. Повторное добавление того же документа в ту же работу сохраняет одну связь.

Перед загрузкой web вычисляет SHA-256 исходного файла и передаёт его в фильтр каталога. Запрос ищет действующие исходники текущей рабочей области с той же контрольной суммой. Совпадение предлагает пользователю выбрать существующий документ или создать отдельный исходник. В работе ранее привязанный исходник можно выбрать повторно, а для новой связи нужна готовая ревизия OCR. При одновременной загрузке обе операции могут создать отдельные исходники.

Версия распознавания в работе обновляется явным действием. Команда закрепляет выбранную готовую версию только в этой работе. При обновлении сверяются текстовые цитаты и контрольные суммы изображений. Значения, у которых пропала часть подтверждённых данных, сохраняются до повторной проверки. Подтверждение снимает отметку о повторной проверке, после чего можно сформировать новый комплект. Повтор команды для уже закреплённой версии безопасен. Добавление источника и обновление версии оставляют запуск анализа за пользователем.

Снятие связи из работы сохраняет документ в каталоге. Удаление в каталоге удаляет исходный документ, результаты его распознавания и все связи с работами после подтверждения показанных пользователю последствий. Если затронутая работа выполняет анализ или генерацию, удаление доступно после завершения запуска.

Участник может удалить документ без связей с работами. Для удаления документа, используемого хотя бы в одной работе, требуется право владельца рабочей области.

Диалог удаления перечисляет затронутые работы. При наличии связей подтверждение требует удержания кнопки в течение трёх секунд или равноценного доступного действия. Если список связей изменился после показа диалога, требуется новое подтверждение.

Удаление убирает ссылки на этот документ из доказательств. Если у подтверждённого сведения больше нет подтверждающих источников, его значение сохраняется для повторной проверки. Уже сформированные комплекты остаются в истории с пометкой об изменении источников. Новая генерация по затронутым сведениям требует проверки.
