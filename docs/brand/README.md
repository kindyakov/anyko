# Anyko — материалы бренда

Начните с [визуального брендбука](brandbook.html): откройте файл в браузере. Он работает локально без подключения к сети.

- [Полные правила и тексты](brandbook.md).
- [CSS-токены](tokens.css).
- [Основной маскот](assets/agent.svg), [альтернативный вариант](assets/agent-2.svg), [исходный PNG](assets/agent.png).
- Логотип для [тёмного](assets/anyko-lockup-dark.svg) и [светлого](assets/anyko-lockup-light.svg) фона.
- [Происхождение материалов](assets/source-manifest.json).
- [Проверка файлов и контраста](verification.json).

Версия 1.1, 4 ноября 2026 года. Исходная графика сохранена без перерисовки. Новые правила оформления адаптированы к подготовке заявлений по БФЛ. Примеры интерфейса статические, сведения в них вымышлены.

Надпись в собранных SVG-логотипах остаётся живым текстом системного шрифта. Изображения новых поз маскота, упрощённая favicon и логотип с текстом в кривых в эту версию не входят.

Типографика: **Onest** — основной, **Manrope** — заголовки, **Unbounded** — редкие акценты. Файлы и лицензии хранятся в `assets/fonts/`.
