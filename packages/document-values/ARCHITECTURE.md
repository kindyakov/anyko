# packages/document-values

Разбор и форматирование значений документов, общие для сборки DOCX в backend и предпросмотра в web: деньги, календарные даты, текст, обязательства, занятость, приложения, раскладка заявления и описи БФЛ. Чистые функции без I/O, HTTP и зависимостей среды; импортировать могут backend и web.

## Устройство

Один файл на тему в `src/`, каждый — отдельный subpath в `exports` (`@anyko/document-values/money`, `/statement-layout`, …). Корневого экспорта нет.

## Как добавлять

- Правило формата, которое нужно и DOCX, и предпросмотру, пишется здесь один раз, а не в feature web и `templates` по отдельности.
- Деньги и даты используют предметное представление из `money.ts` и `calendar-date.ts`; float не используется для сумм.
- Новый файл получает subpath в `package.json`. Собственных тестов у пакета нет: поведение проверяют тесты бланков в `packages/backend/tests` (`test:works`) и model-тесты `fact-review` в web.
- Сейчас часть правил выбирается сравнением строки версии бланка. Новые такие ветвления не добавляйте без нужды: [ADR 0012](../../docs/adr/0012-processing-profiles-and-package-descriptions.md) переводит их в описание пакета и одну функцию заполнения (#91, #92).
