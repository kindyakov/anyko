# packages/eslint-config

Общие правила ESLint flat config: `base` (typescript-eslint `strictTypeChecked`), `server`, `frontend` (Next и тесты web) и `architecture.js` — список I/O-глобалов и правило `architecture/no-cross-package-source` (запрет импорта исходников соседнего пакета). Применение по папкам (`domain`, `profiles`, `http/routes`, features web, `packages/ui`) задаёт корневой `eslint.config.mjs`.

## Как добавлять

- Правило вводится после повторившейся ошибки или вместе с новым соглашением и выражается через папку или соглашение, а не через перечень конкретных файлов. У него есть пример с намеренным нарушением, на котором оно падает, и сообщение с указанием, как исправить.
- Ослабление правила или новое исключение — отдельный пункт Code review с причиной и условием удаления. Точечное отключение: `eslint-disable-next-line <правило> -- <причина>`.
- Обновление `strictTypeChecked` и версий плагинов рассматривается как изменение правил.
