# packages/llm

Серверный gateway OpenAI-совместимого SDK. Создаёт модель по явно переданным настройкам подключения, читает опубликованные пределы маршрута (`ModelContextLimits`), передаёт потоковые ответы и наблюдатель вызовов провайдера. Не знает Prisma, пользователей, файлов, очередей и промптов. Импорт запрещён web, contracts и ui.

## Устройство

```text
src/index.ts             публичный интерфейс
src/router-context.ts    пределы контекста и ответа маршрута
src/provider-stream.ts   потоковый транспорт и таймаут тишины
src/provider-calls.ts    наблюдатель вызовов: расход, время, ошибки
src/local-trace.ts       локальная трассировка запросов модели
```

## Как добавлять

- Промпты, инструменты агента и правила проверки ответа принадлежат `backend/modules/agents` и профилю, а не этому пакету.
- Пакет сообщает опубликованные пределы маршрута, а предел ответа рассчитывает `backend/modules/agents/infrastructure/context-budget.ts`: один для всех вызовов, при неизвестном максимуме — 64 000 ([work-pipeline.md](../../docs/engineering/work-pipeline.md)).
- Ошибка провайдера отображается в типизированный код (`LLM_*`) без смены модели или провайдера; повторяется только распознанная временная ошибка ([правила кода](../../docs/engineering/code-rules.md#ошибки-и-побочные-эффекты)).
- Тесты (`bun test src`) работают с контролируемым HTTP-провайдером; платных вызовов в них нет.
