Anyko для Windows x64

1. Распакуйте папку в короткий личный каталог, доступный для записи только вам.
   Если путь содержит кириллицу или другие не-ASCII символы, Windows должна
   предоставлять для него короткое имя 8.3. При сообщении об ошибке перенесите
   всю папку в короткий путь из латинских букв и цифр.
2. Запустите Anyko.exe. При первом запуске подготовка может занять несколько минут.
3. Когда сайт откроется в браузере, данные для входа находятся в data\login.txt.
4. Чтобы завершить работу, вернитесь в окно Anyko и нажмите Enter.

Документы, пароли и ключи находятся в папке data. Приложение наследует права
доступа родительского каталога и не настраивает их автоматически. Перед запуском
убедитесь в свойствах Windows, что другие пользователи не имеют доступа к папке.
Перед копированием, переносом или обновлением остановите Anyko и дождитесь
закрытия окна: копирование работающих хранилищ может повредить резервную копию.
Сохраняйте data при обновлении. Для работы облачного AI потребуется
интернет и собственные настройки провайдера в приложении.

Если запуск не удался, журналы находятся
в data\logs. Не отправляйте настройки и журналы посторонним без проверки.
